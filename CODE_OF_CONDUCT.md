# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good faith, keep disagreements about the work. Report unacceptable behaviour privately to the maintainers through [a private security advisory](https://github.com/Primaris-Research-Group/procurator/security/advisories/new) (it reaches only them), marked "conduct". Maintainers may remove, edit or reject contributions and may ban contributors for behaviour they judge inappropriate, threatening, offensive or harmful.
